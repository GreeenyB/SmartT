# SmartT Demo Video

Large video-production assets are intentionally excluded from this repository.

This includes:

- intermediate renders
- review exports
- audio-production workspaces
- Playwright/browser runtimes
- temporary build files
- large delivery archives

The SmartT repository focuses on firmware, software, dashboard, web,
architecture, diagnostics, scripts, and technical documentation.

Final competition/demo videos should be distributed separately, such as
through a GitHub Release or external media storage.
